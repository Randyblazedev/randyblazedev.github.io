I Learned Tailwind Before I Learned CSS

When people ask how I learned Tailwind CSS, they expect a perfect roadmap. That's not what happened. This is the messy, real version.

When people ask how I learned Tailwind CSS, they usually expect me to say I followed a perfect roadmap or spent weeks studying documentation. That is not what happened. My journey into frontend development was different.

Chapter 1 — HTML First

I started learning HTML through FreeCodeCamp. It helped me understand how websites are structured and introduced me to the foundation of the web. I learned how to create headings, paragraphs, images, links, forms, and the basic structure behind webpages.

After becoming comfortable with HTML, I wanted to make my websites look better. That is when I discovered Tailwind CSS.

Chapter 2 — The First Class

I added the Tailwind CDN to my HTML project, refreshed the browser, and typed my first utility class: 

<div class="bg-blue-400">Hello</div>

I saved the file and refreshed the page. The background turned blue. It was a simple moment, but it made me curious about what else I could build.

"It was a simple moment — the background turned blue — but it made me curious about what else I could build."

Chapter 3 — Building by Doing

I started experimenting with more classes. I learned how to add spacing, rounded corners, shadows, Flexbox, and Grid. I was not just memorizing classes. I was learning by creating things. Every project taught me something new.

But after some time, I realized that while I could build interfaces with Tailwind CSS, I did not fully understand the CSS concepts behind those utilities.

🏁 Realization

I could build interfaces with Tailwind, but I didn't understand the CSS behind it. That's when I decided to learn CSS properly.

Chapter 4 — Learning CSS Properly

I started learning CSS with Claude as my mentor and focused on understanding the fundamentals behind modern web design. Suddenly, Tailwind CSS became much easier to understand. The utility classes I was using were no longer just shortcuts. I understood the ideas behind them.

After improving my CSS skills, I started taking on Frontend Mentor challenges. Those challenges helped me practice building real designs, improving responsive layouts, understanding spacing, and writing cleaner code. Each challenge pushed me to improve.

Chapter 5 — The Lesson

Looking back, my learning path was not the traditional one. Many people learn HTML → CSS → Tailwind CSS. My journey was HTML → Tailwind CSS → CSS → Frontend Mentor → More frontend skills.

🧠 Developer note

There is no single perfect way to learn programming. The most important thing is to keep building, experimenting, and improving. Projects can teach lessons that tutorials cannot always provide.

Chapter 6 — The Journey Continues

Today, I am continuing to improve my frontend skills, build projects, and share my journey through this blog. My next big chapter is JavaScript, and I am excited to see where this path leads.

If you are starting your own coding journey, do not wait until you know everything before building. Sometimes, one small thing like bg-blue-400 can be the beginning of something much bigger.
